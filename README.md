# ItemSetInfo · 物品套装信息

在物品简介旁显示所属套装的效果和全部部件。支持一个物品属于多个套装，并用【】标记当前物品。界面沿用游戏原生风格；只显示资料，不改变套装效果。

## 安装（Windows）

需要 [Mewjector API v3](https://www.nexusmods.com/mewgenics/mods/218)。此版本适配 Mewgenics Steam Build 25143593。

1. 退出游戏，将压缩包内的 `ItemSetInfo` 文件夹解压到游戏的 `mods` 目录。
2. 手动使用 Mewjector 时，在游戏根目录 `chainloader.ini` 的 `[LoadOrder]` 下追加连续编号，例如 `Mod3=ItemSetInfo\ItemSetInfo.dll`；编号接在已有条目后。
3. 启动游戏，将鼠标移到带套装的物品上查看。

移除时退出游戏，把 `ItemSetInfo` 文件夹移出 `mods`。
